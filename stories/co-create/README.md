# BECOMING — ZOONN × AI

打开 index.html 即可浏览。推荐用现代 Chrome、Edge、Firefox 或 Safari；本地服务器与静态托管也可运行。
没有安装、构建或后端依赖。英文主视觉，正文可在中文 / 英文之间切换。

## 内容与交互
- 实时 WebGL 参数化雕塑；随滚动从环形变为交织、绽放形态。
- 作品：ZOONN 之城、琴步电子琴原型、专注小屋；Dify 工作流明确标为探索中。
- 实验室：三种形态、银色/钴蓝材质、强度滑块、拖动/方向键旋转、重置。
- 七个可发声的琴键为项目交互演绎，非完整电子琴软件。
- 顶部暂停按钮；遵循系统减少动态效果；隐藏页面停止绘制；WebGL 不可用显示静态替代。
- 邮件、GitHub 链接及复制微信号；复制失败时直接显示微信号。

## 部署
独立包：把整个目录上传到静态托管，保留 assets 与 demos 目录结构，index.html 位于根目录。
独立包包含专注小屋，游戏返回作品展；城市入口指向 https://zoonn.org/。
项目副本内的版本：stories/co-create/index.html，城市与游戏使用站内相对链接。
本次未部署任何线上服务。远程城市和 GitHub 是否可访问取决于用户网络与站点状态。

## 编辑
index.html：内容、data-en 英文翻译；style.css：视觉与响应式；sculpture.js：雕塑与材质；app.js：交互。
fonts.css 与 assets：本地字体、用户照片、城市图。字体来源与许可链接见 assets/FONT-SOURCES.txt；Noto OFL 附带。
中文字体按当前文案子集化，新增中文字符会回退系统字体；新增大段文案时请更新字体子集。
动画不是视频，画面随时间与操作变化。设备性能与 WebGL 支持会影响流畅度；移动端降低像素密度和绘制频率。
